# 项目过程记录

## 项目概述
- 项目：AI 伪造图像检测与解释
- 核心目标：
  1. 伪造检测 / 分类
  2. 伪造解释 / 生成文字说明
  3. 痕迹定位 / 分割伪造区域

#### 当前理解
- 这个项目不只是判断图片真假，还要求说明伪造原因，并指出伪造区域
- 解释任务中的伪造痕迹大致可分为：
  - Physics：光照、反射、透视、物理规律违背
  - Distortion：颜色纹理失真、噪声模糊、材质表达错误、风格异常
  - Structure：物体变形、不对称、文字结构异常等
- 当前判断是：SynthScars 主要提供伪造痕迹相关标注，更适合用于解释与定位任务，不太适合作为“真假分类”任务的完整训练依据
- 当前数据集选择上，不使用 Holmes
- 真假分类任务将额外引入 GenImage 数据集，并先采用其中一部分数据开展训练与验证
- 当前多任务框架已经可以完成基础训练、开发评估、课程验收评估和单图推理流程
- 课程验收数据集不是统一多任务同图评估集，而是分类、解释、定位三个独立子集，因此最终验收应当是同一个模型分别在三部分数据上评估后汇总指标
- 先前定位指标全 0 的主因已经确认并修复，当前旧的正式训练 checkpoint 不再可信，因为它是在错误定位监督下训练出来的
- 当前分类任务的另一个关键问题也已经明确：课程 fake 数据生成器种类比原始 ADM 训练集丰富得多，因此后续分类训练必须继续扩充多生成器数据来源，不能只依赖单一 ADM

#### 下一步
- 基于修复后的 mask 监督和新的多数据源分类配置重新运行正式训练，生成新的 `outputs/best.pt`
- 用新的正式训练模型重新跑课程验收评估，观察分类、解释、定位三项最终结果
- 重点关注课程分类中的 fake 召回是否较之前提升，以及定位指标是否在正式训练后继续提升
- 如有需要，再继续补充更多生成器数据源，或继续优化定位头结构、损失权重与训练轮数
