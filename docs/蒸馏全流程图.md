# 蒸馏全流程图

本文给出当前项目的蒸馏端到端流程，覆盖三条路径：

1. 离线缓存蒸馏（offline_cache）
2. 在线 EMA 自蒸馏（ema_online）
3. 方案三：线上大模型教师 -> 离线缓存蒸馏

```mermaid
flowchart TD
    A[开始] --> B[准备配置与数据]
    B --> C{选择蒸馏模式}

    C -->|disabled| Z1[仅监督训练 train_multitask.py]
    Z1 --> Z2[验证与保存 checkpoint]

    C -->|offline_cache| O1[准备教师来源]
    O1 --> O2{教师来源类型}
    O2 -->|本地教师 checkpoint| O3[运行 distill/build_cache.py]
    O2 -->|线上大模型输出 JSONL| O4[运行 distill/build_cache_from_llm.py]
    O3 --> O5[得到 teacher_cache.pt]
    O4 --> O5
    O5 --> O6[train_multitask.py Stage B 按 image_path 查询缓存]
    O6 --> O7[监督损失 + 蒸馏损失]
    O7 --> O8[验证与保存 best.pt/latest.pt]

    C -->|ema_online| E1[init_ema_teacher]
    E1 --> E2[学生前向 + 教师前向]
    E2 --> E3[compute_online_distill_loss]
    E3 --> E4[反向更新学生]
    E4 --> E5[update_ema_teacher]
    E5 --> E6[验证与保存 checkpoint]

    B --> L0{是否使用方案三流水线}
    L0 -->|是| L1[distill/run_llm_distill_pipeline.py]
    L1 --> L2[collect_llm_teacher.py 采集 teacher JSONL]
    L2 --> L3[build_cache_from_llm.py 构建 teacher_cache]
    L3 --> L4[train_multitask.py 执行 offline_cache 训练]
    L4 --> L5[compare_checkpoints.py 对比 baseline 与 candidate]
    L5 --> L6[输出指标差值与结论]
```

## 关键脚本对照

1. 统一流水线：`distill/run_llm_distill_pipeline.py`
2. 线上教师采集：`distill/collect_llm_teacher.py`
3. JSONL 转缓存：`distill/build_cache_from_llm.py`
4. 本地教师转缓存：`distill/build_cache.py`
5. 训练入口：`train_multitask.py`
6. 指标对比：`distill/compare_checkpoints.py`

## 典型执行顺序（方案三）

1. 调用 `distill/run_llm_distill_pipeline.py`。
2. 自动执行教师采集并落盘 JSONL。
3. 自动构建 `teacher_cache.pt`。
4. 自动调用训练脚本完成蒸馏训练。
5. 可选对比 baseline 与蒸馏模型并输出指标增减。

## 产物清单

1. 教师原始输出：`distill/llm_teacher_outputs*.jsonl`
2. 教师缓存：`distill/teacher_cache_from_llm*.pt`
3. 训练权重：`outputs*/best.pt` 与 `outputs*/latest.pt`
4. 指标对比：终端输出（可重定向保存为日志）
