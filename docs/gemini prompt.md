## 第 6 页｜问题修复
**标题**：问题修复：定位全 0 的根因与闭环验证  
**关键结论**：修复 mask 前景值后，定位指标恢复非零，单图推理 mask 不再纯黑。

**问题原因**：
- `polygon_to_mask()` 前景值错误设为 1
- 经 `ToTensor()` 后前景变为 1/255
- 在 `>0.5` 阈值下被全部清空
- 导致训练与评估长期使用全零 mask 监督

**修复方式与结果**：
- 前景值由 1 改为 255
- 修复后 smoke：
  - IoU = 0.1048
  - PixP = 0.3013
  - PixR = 0.1662
  - PixF1 = 0.2142
- 再次单图推理：预测 mask 不再是纯黑图
