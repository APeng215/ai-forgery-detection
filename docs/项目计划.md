# 项目计划

## 一、项目目标
本项目围绕 AI 伪造图像分析展开，计划完成以下三个目标：

1. **真假分类**
   - 判断输入图像是真实图像还是 AI 生成 / 伪造图像。
   - 评价指标：Acc、AP。

2. **伪造解释**
   - 对图像中的伪造痕迹进行文字说明，解释图像为什么可疑。
   - 评价指标：BLEU、ROUGE-L。

3. **痕迹定位**
   - 对图像中的伪造区域进行定位，输出对应的区域掩码或分割结果。
   - 评价指标：IoU、PixP、PixR、PixF1。

## 二、数据集与任务对应关系
### 1. 课程数据集
- `data/2026-课设数据集/` 用于**最终课程验收**。
- 该数据集**不参与模型训练**，只用于最后测试、整理结果和课程展示。

### 2. 真假分类训练数据
- 使用数据集：`data/imagenet_ai_0508_adm/`
- 当前结构：
  - `train/ai`：162000 张
  - `train/nature`：157453 张
  - `val/ai`：6000 张
  - `val/nature`：6000 张
- 任务定位：用于目标一“真假分类”。
- 当前策略：不全量训练，先选取其中**一部分数据**完成 baseline，后续再视训练速度和效果扩大规模。

### 3. 解释与定位训练数据
- 使用数据集：`data/SynthScars/`
- 当前结构：
  - `train/images`：11182 张
  - `train/annotations/train.json`
  - `test/images`：1000 张
  - `test/annotations/test.json`
- 标注特点：
  - 每张图包含 `caption`
  - 每个伪造痕迹包含 `sentence`、`explanation`
  - 定位信息以 `segmentation` 多边形形式提供
- 任务定位：用于目标二“伪造解释”和目标三“痕迹定位”。

### 4. 不使用的数据集
- 当前方案中**不使用 Holmes**。

## 三、基于数据结构的训练思路
### 目标一：真假分类
#### 数据使用方式
- 使用 `imagenet_ai_0508_adm` 的 `train` 和 `val`。
- `ai` 作为伪造类，`nature` 作为真实类。
- 第一版训练不追求全量覆盖，而是优先保证训练流程可运行、指标可复现。

#### baseline 方案
- 采用**图像二分类模型**作为 baseline。
- 优先考虑轻量且成熟的分类骨干，例如：
  - ResNet50
  - EfficientNet-B0 / B2
  - ConvNeXt-Tiny
- 第一阶段优先使用单模型，不做复杂集成。

#### 训练规模规划
考虑到训练环境为 **RTX 5070 Ti**，计划采用“先小后大”的策略：
- 第 1 轮：每类先取 1 万张，共约 2 万张训练，快速验证流程。
- 第 2 轮：若训练速度和显存表现稳定，扩大到每类 2 万到 5 万张。
- 验证集优先直接使用现有 `val`，必要时再做子集验证。

#### 训练配置建议
- 输入分辨率：优先从 `224 x 224` 开始。
- batch size：根据显存从 16、32 逐步试。
- 使用混合精度训练。
- 优先记录 Acc、AP，并保留混淆矩阵与典型误判样本。

### 目标二：伪造解释
#### 数据使用方式
- 使用 SynthScars 的 `caption` 作为整体解释目标。
- 使用 `refs` 中的 `sentence + explanation` 作为更细粒度的伪造说明监督。

#### baseline 方案
为了兼顾效果和 5070 Ti 的训练成本，解释任务分两步推进：

1. **第一版：模板/检索式解释 baseline**
   - 从训练集提取常见伪造类型和表述模式。
   - 基于图像特征检索相似样本，输出对应 explanation 或 caption。
   - 这一版实现简单，能快速得到 BLEU、ROUGE-L 基线。

2. **第二版：轻量生成式 baseline**
   - 使用视觉编码器 + 轻量语言解码器，或直接微调较小的视觉语言模型。
   - 若显存压力较大，优先采用 LoRA / 参数高效微调。
   - 训练目标先对齐整体 `caption`，后续再尝试细粒度 refs 融合。

#### 训练重点
- 先保证能生成“有意义的伪造描述”，再优化措辞质量。
- 先跑通 BLEU、ROUGE-L 评估流程。
- 如生成式方案成本过高，课程设计中也可以保留“检索式 baseline + 分析说明”的方案。

### 目标三：痕迹定位
#### 数据使用方式
- 将 SynthScars 中的 `segmentation` 多边形转换为二值 mask。
- 若一张图有多个 refs，则合并成单张 mask，先完成单类前景分割 baseline。

#### baseline 方案
- 优先使用成熟的语义分割架构：
  - U-Net
  - DeepLabV3
  - SegFormer-B0/B1
- 第一版以“伪造区域 / 非伪造区域”的二分类分割为主，不先做复杂的痕迹类型分割。

#### 训练配置建议
- 输入分辨率优先从 `256 x 256` 或 `384 x 384` 开始。
- 先使用 BCE + Dice loss 或 Dice + Focal loss。
- 重点监控 IoU、PixP、PixR、PixF1。

## 四、整体执行顺序
### 第一阶段：数据准备
1. 整理 `imagenet_ai_0508_adm` 的抽样方案。
2. 编写 SynthScars 标注解析脚本：
   - 读取 `caption`
   - 读取 `refs`
   - 将 `segmentation` 转成 mask
3. 明确课程验收数据的输入输出格式，但暂不用于训练。

### 第二阶段：三个 baseline 依次落地
1. **先做真假分类 baseline**
   - 最容易起步
   - 能快速验证训练环境、日志记录、评估流程是否正常
2. **再做痕迹定位 baseline**
   - SynthScars 的 segmentation 标注较直接
   - 结果也更容易可视化展示
3. **最后做伪造解释 baseline**
   - 解释任务实现难度相对更高
   - 放在分类与定位跑通后推进更稳妥

### 第三阶段：联合整理与课程验收
1. 用训练好的三个模块分别对课程验收数据进行预测。
2. 整理真假分类结果、解释文本结果、定位可视化结果。
3. 形成课程展示所需的实验表格、案例图和结论分析。

## 五、5070 Ti 环境下的资源规划
- 默认采用单卡训练。
- 优先使用混合精度。
- 优先从小模型、小分辨率、小样本子集启动。
- 避免一开始就做多任务联合训练，先分别训练三个任务的 baseline。
- 解释任务若涉及大模型微调，优先考虑：
  - 冻结大部分参数
  - 使用 LoRA
  - 控制最大文本长度
  - 必要时先退回检索式方案

## 六、近期执行重点
1. 先完成 `imagenet_ai_0508_adm` 抽样训练方案。
2. 完成 SynthScars 标注解析与 mask 生成方案。
3. 优先实现真假分类 baseline。
4. 在分类 baseline 稳定后，再进入定位与解释任务。

## 七、当前已确定的决策
- `data/2026-课设数据集/` 仅用于最终课程验收，不参与训练。
- 真假分类任务使用 `imagenet_ai_0508_adm`。
- 伪造解释与痕迹定位任务使用 `SynthScars`。
- 当前不使用 Holmes 数据集。
- 训练环境按单张 **5070 Ti** 规划，优先保证 baseline 可训练、可复现、可展示。

## 八、预期产出
- 一个面向课程验收的三任务方案。
- 真假分类、伪造解释、痕迹定位三个 baseline。
- 对课程验收数据的最终预测结果。
- 一份完整的过程记录、实验分析和课程汇报材料。
